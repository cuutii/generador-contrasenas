# 🔐 Generador de Contraseñas

App web para crear contraseñas seguras y aleatorias en segundos. Elegís la longitud y qué tipos de caracteres incluir, y la aplicación te muestra la contraseña generada junto con un medidor de fortaleza en tiempo real.

## Características

- Longitud ajustable de **8 a 32** caracteres con un control deslizante.
- Opciones para incluir mayúsculas, números y símbolos (las minúsculas siempre están incluidas).
- Medidor de fortaleza en tiempo real con indicador visual.
- Botón **Copiar** para llevar la contraseña al portapapeles de un solo clic.
- Interfaz clara, accesible y adaptada a pantallas chicas.
- **Sin dependencias**: HTML + CSS + JavaScript puro, funciona offline.

- HTML5
- CSS3
- JavaScript (vanilla, sin librerías)

## Cómo usarlo

1. Descargá el repositorio.
2. Abrí `index.html` en tu navegador (doble clic, no necesita servidor).
3. Ajustá la longitud y las opciones, presioná **Generar** y listo.
